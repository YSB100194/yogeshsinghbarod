# YSB Engineering — Leadership Portfolio 2.0

A privacy-conscious, static professional portfolio emphasizing engineering leadership, architecture, and business impact.

## Preview
Open `index.html` locally in a browser. No build step or third-party dependencies.

## Publish
1. Review every public claim and diagram. Remove anything confidential or not approved for external disclosure.
2. Update `assets/site.js` with your public GitHub profile and professional email.
3. Create a GitHub repository named `<username>.github.io`.
4. Push these files to the `main` branch.
5. Under **Settings → Pages**, choose **GitHub Actions**.
6. The workflow publishes only `index.html` and `assets/`, not repository configuration files.

## Accuracy and privacy
- No private source code, proprietary architecture, client-specific details, or unapproved metrics should be published.
- Case studies are generic reference patterns. Leadership scenarios are prompts for substantiated stories, **not** verified outcomes.
- Replace generic cases with approved facts and evidence before treating them as personal achievements.
- The ₹1 crore compensation goal and HBS MBA aspiration are intentionally absent from the public site.
- Credential verification URLs should be added only after verifying ownership and public accessibility.
- Published HTML, JavaScript, CSS, and assets are always public.

## Editorial upgrade plan
For each case study, capture: challenge, scope, your individual role, decision, alternatives, collaboration, business outcome, and permitted evidence. For MBA-oriented narratives, emphasize leadership choices and reflection rather than prestige claims.
